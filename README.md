# Operating System Exercises

A collection of Bash shell scripting exercises written as part of an Operating Systems course. Each script is self-contained and demonstrates a core shell scripting concept, progressing from basic output to arrays, loops, and control flow.

## Overview

| # | Script | Concept |
|---|--------|---------|
| 01 | `Print Any Message.sh` | Basic output with `echo` |
| 02 | `Display Variable.sh` | Variable declaration and expansion |
| 03 | `ReadInput&Display.sh` | Reading multiple inputs with `read` |
| 04 | `ReadPromptDisplay.sh` | Prompted input using `read -p` |
| 05 | `ReadSilentDisplay.sh` | Silent (hidden) input using `read -sp` |
| 06 | `ArithmeticOperations.sh` | Arithmetic expansion (`+ - * / % ++ --`) |
| 07 | `CompareVariable.sh` | Relational comparisons with `if`/`else` |
| 08 | `OddEvenCheck.sh` | Modulus check for odd/even numbers |
| 09 | `CompareThreeNumbers.sh` | Finding the greatest of three numbers |
| 10 | `FileExistenceCheck.sh` | File existence test with `-e` |
| 11 | `ArrayCount.sh` | Array declaration and element count |
| 12 | `ArrayIterations.sh` | Iterating over an array with `for` |
| 13 | `Sumof1toN.sh` | Summation using a `for` loop |
| 14 | `SumofEvenNumbers.sh` | Summing even numbers in a range |
| 15 | `Factorial.sh` | Factorial calculation with a `for` loop |
| 16 | `ReverseCountdown.sh` | Reverse iteration (countdown) |

## Requirements

- A Unix-like environment (Linux, macOS, or WSL on Windows)
- Bash (version 4 or later recommended)

## Usage

Clone the repository:

```bash
git clone https://github.com/MosaddekHossainMehedi/OperatingSystemExcercises.git
cd OperatingSystemExcercises
```

Make a script executable and run it:

```bash
chmod +x "01. Print Any Message.sh"
./"01. Print Any Message.sh"
```

Alternatively, run any script directly with `bash`, without changing permissions:

```bash
bash "06. ArithmeticOperations.sh"
```
